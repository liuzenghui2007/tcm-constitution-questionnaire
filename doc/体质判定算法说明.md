# 中医体质判定算法说明

## 1. 文档目的

本文档归纳本仓库（`tcm-constitution-questionnaire`）中 **体质转化分与判定结果** 的计算方式、与源码文件的对应关系，以及 **极端填答算例** 的验算结论。正式条文以 **GB/T 46939-2025** 印刷版或授权电子文本为准。

## 3. 逆向计分

对需要逆向的条目，将用户所选分值 $v$（$v \in \{1,2,3,4,5\}$）按下式换算后再参与求和：

$$
v' = 6 - v
$$

实现函数：`reverseScore(value)`。

## 4. 原始分与转化分

对某一种体质，在按性别过滤掉不适用条目后，设参与计分的条目数为 $n$，各条目计分（已按该体质规则做逆向或正向）之和为原始分 $R$。

转化分（与需求文档中的国标写法一致）：

$$
T = \frac{R - n}{n \times 4} \times 100
$$

其中：

- $R$：原始分；
- $n$：该体质下适用条目的数量（湿热质等含性别专属题时，$n$ 随性别变化）；
- $T$：转化分，理论范围 $[0, 100]$（全选最低档与全选最高档在纯正向或纯逆向理想情形下对应 $0$ 与 $100$）。

实现：`calculateRawScore`、`calculateTransformedScore`。

## 5. 偏颇体质判定

设某偏颇体质转化分为 $T$，判定结果为三档之一：

| 条件 | 结果 |
|------|------|
| $T \geq 40$ | 是 |
| $30 \leq T \leq 39$ | 倾向是 |
| $T < 30$ | 否 |

实现：`judgeBiasedConstitution`。

八种偏颇可同时出现多种「是」或「倾向是」，与国标「多体质并存」的表述一致。

## 6. 平和质判定

设平和质转化分为 $T_0$，其余八种偏颇体质的转化分为 $T_1,\ldots,T_8$。

实现顺序（与 `judgeBalancedConstitution` 一致）：

1. 若 $T_0 \geq 60$ 且 $\forall i,\, T_i < 30$，则 **是**。
2. 否则若 $T_0 \geq 60$ 且 $\forall i,\, T_i < 40$，则 **基本是**（典型情形：至少某一偏颇在 $[30,40)$；若全部 $<30$ 已由上一分支判为「是」）。
3. 否则 **否**。

当 $T_0 < 60$ 时，直接为「否」。

实现函数：`judgeBalancedConstitution`。

## 7. 计算流程（`evaluateConstitution`）

1. 对九种体质分别计算 $(R,\,n)$ 与转化分 $T$。
2. 先对八种偏颇套用 **偏颇判定** 写入 `judgment`。
3. 再对平和质套用 **平和判定**（依赖八种偏颇的转化分数组）。

顺序保证平和判定使用的是已算好的偏颇转化分。

## 8. 极端算例：每题均选「总是」（分值为 5）

在 **当前 `questions.json`（附录 A 对齐版）** 下：

- 八种偏颇体质的计分条目均为 **正向**。若某体质下每题均选 $5$，则 $R=5n$，$T=\dfrac{5n-n}{4n}\times 100=100$，故凡 $n\geq 1$ 的偏颇表判定均为 **「是」**（湿热、特禀在单性别下 $n$ 为 3，仍为 $100$）。
- **平和质（表 A.1）** 为 **1 条正向 + 3 条逆向**（q1 正向；q2、q3、q4 带 * 逆向）。均选 $5$ 时：$R=5+1+1+1=8$，$n=4$，转化分 $T_0=\dfrac{8-4}{16}\times 100=25$，因 $T_0<60$，平和质为 **「否」**。

平和质条目与逆向标记：

| 题目 ID | 逆向 |
|---------|------|
| q1 | 否 |
| q2 | 是 |
| q3 | 是 |
| q4 | 是 |

该算例用于回归：**平和转化分 25、平和「否」、八种偏颇均为「是」**（在「全选总是」且各体质条目均适用时）与公式一致。
