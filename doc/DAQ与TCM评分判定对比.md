# DAQ 与 TCM 评分判定对比

## 转化分公式 — 相同

两者都用同一个公式：

```
T = (R - n) / (n × 4) × 100
```

- R：原始分（各条目分值之和）
- n：该体质下适用条目数量
- T：转化分，范围 [0, 100]

## 偏颇体质判定阈值 — 相同

| 条件        | DAQ    | TCM    |
| ----------- | ------ | ------ |
| T ≥ 40      | 是     | 是     |
| 30 ≤ T < 40 | 倾向是 | 倾向是 |
| T < 30      | 否     | 否     |

## 平和质判定 — 有差异

| 逻辑                    | DAQ                | TCM (GB/T 46939-2025) |
| ----------------------- | ------------------ | --------------------- |
| T₀ ≥ 60 且所有偏颇 < 30 | 是                 | 是                    |
| T₀ ≥ 60 且所有偏颇 < 40 | —                  | 基本是                |
| T₀ ≥ 60 但有偏颇 ≥ 40   | 不判定（直接跳过） | 否                    |
| T₀ < 60                 | 不判定             | 否                    |

DAQ 的平和质判定更粗糙：只要有任何偏颇体质"是"（confirm > 0），就完全跳过平和质判定。TCM 多了一个"基本是"档位。

## 结果展示 — 核心差异

|          | DAQ                               | TCM                    |
| -------- | --------------------------------- | ---------------------- |
| 展示数量 | **只显示 1 个**（分数最高的"是"） | 显示所有"是"和"倾向是" |
| 排序     | 按分数降序，取第一个              | 全部列出               |
| 无偏颇时 | 默认显示平和                      | 显示平和判定结果       |

## 题目数量 — 有差异

|              | DAQ                         | TCM                      |
| ------------ | --------------------------- | ------------------------ |
| 总题数       | 约 33 题（每种体质 7-8 题） | 27 题（每种体质 3-4 题） |
| 每体质条目数 | 6-8 个                      | 3-4 个                   |
| 标准依据     | 旧版（2009）                | GB/T 46939-2025          |

## 结论

**评分公式和判定阈值（30/40/60）两者一致**，核心差异在于：

1. **题目数量**：DAQ 用旧版标准（每体质 7-8 题），TCM 用 2025 新国标（每体质 3-4 题）
2. **结果展示**：DAQ 只显示最高分的 1 个体质，TCM 显示所有达标的
3. **平和质**：TCM 多了"基本是"档位，DAQ 没有
