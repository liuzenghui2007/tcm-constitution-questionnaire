1. 您胃脘部、背部或腰膝部怕冷吗？  
2. **您感到怕冷、衣服比别人穿得多吗？**

### 表 A.4 阴虚质（3 条）

1. 您感觉身体、脸上发热吗？

3. **您面部两颧潮红或偏红吗？**

### 表 A.5 痰湿质（3 条）

1. **您感到身体沉重不轻松或不爽快吗？**  
2. 您腹部肥满松软吗？  
3. 您嘴里有黏黏的感觉吗？

### 表 A.6 湿热质（4 条，含性别限定）

1. 您面部或鼻部有油腻感或者油亮发光吗？  
2. **您小便时尿道有发热感、尿色浓（深）吗？**  
3. 您带下色黄（白带颜色发黄）吗？（限女性回答）  
4. 您的阴囊部位潮湿吗？（限男性回答）

### 表 A.7 血瘀质（3 条）

1. **您身体上有哪里疼痛吗？**  
2. **您面色晦暗或容易出现褐斑吗？**  
3. 您口唇颜色偏暗吗？

### 表 A.8 气郁质（3 条）

1. 您感到闷闷不乐、情绪低沉吗？  
2. 您容易精神紧张、焦虑不安吗？  
3. **您多愁善感、感情脆弱吗？**

### 表 A.9 特禀质（4 条）

1. 您没有感冒时也会打喷嚏吗？  
2. 您容易过敏（对药物、食物、气味、花粉或在季节交替、气候变化时）吗？  
3. **您的皮肤容易起荨麻疹（风团、风疹块、风疙瘩）吗？**  
4. **您的皮肤一抓就红，并出现抓痕吗？**
